# VirtuBox Data Analyst Assessment

## Data Analyst Assessment Project – Business Analysis

This project was completed as part of the VirtuBox Data Analyst Assessment.

### Objective
The objective of this project is to analyze a publicly available business dataset, identify meaningful trends and business opportunities, and provide data-driven recommendations for management.

### Project Components
- Dataset and data preparation
- Data cleaning and preprocessing
- Exploratory data analysis
- Business insights
- Hypothesis testing
- Data quality and limitations
- Actionable recommendations
- Interactive dashboard
- Management presentation

### Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Sheets
- Looker Studio
